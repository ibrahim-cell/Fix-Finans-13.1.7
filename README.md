# Fix Finans Android — 13.2

Bu proje, `Fix2013_2_fix20_splash_logo_fixed.zip` içindeki Fix Finans 13.2 web uygulamasını Android WebView uygulamasına paketler.

## GitHub'a yükleme
1. GitHub'da `Fix-Finans-Android` adlı boş bir repository oluştur.
2. Bu klasörün **içindeki** dosya ve klasörleri repository köküne yükle. ZIP dosyasını yükleme.
3. `Actions` sekmesine gir. `Build Fix Finans APK` workflow'u otomatik çalışır.
4. Build tamamlanınca workflow içindeki **Artifacts** bölümünden `Fix-Finans-13.2-debug-apk` dosyasını indir.

## Android Studio
Projeyi Android Studio ile açıp `Build > Build APK(s)` seçeneğiyle de APK oluşturabilirsin.
